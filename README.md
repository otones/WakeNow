# WakeNow

Windows 局域网唤醒（Wake-on-LAN）小工具。双击运行，弹出机器列表，看谁在线、勾选离线机器、一键唤醒。

![主窗口](shots/light.png)

## 功能

- **机器列表**：展示已录入机器（名称 / MAC / IP），支持搜索、排序
- **在线状态**：后台每 3 秒探测一轮，在线 🟢 / 离线 ⚫ / 唤醒中 🟡 / 未知 ⚪
- **双路探测**：ICMP ping 优先，失败再用 TCP 端口兜底——**防火墙禁 ping 的机器也能正确识别**
- **多选批量唤醒**：复选框多选，或一键「全选离线」，点「唤醒选中」批量发送魔术包
- **状态跟踪**：唤醒后行变「唤醒中」，探测通过自动转在线，3 分钟未通则回退离线
- **机器管理**：添加 / 编辑 / 删除，输入时实时校验 IP、MAC 格式
- **扫描内网**：自动发现局域网内设备，**边扫边显示**，勾选批量保存
- **托盘常驻**：点 × 隐藏到托盘，后台继续探测；托盘菜单可快速唤醒
- **单实例**：重复启动不会开第二个窗口，只会把已有窗口唤到前台
- **开机自启**：写 HKCU 注册表，可在托盘菜单开关
- **导入导出**：JSON 格式，支持合并（按 MAC 去重）或替换
- **双主题**：浅色 / 深色 / 跟随系统，可随时切换
- **窗口可拉伸**：拖拽任意边缘调整大小，列表区自适应
- **零依赖**：单 exe，免安装，无需管理员权限

## 使用

1. 下载 `WakeNow.exe`，放到任意目录
2. 双击运行
3. 首次会看到空状态。两种录入方式：

   **方式 A：扫描内网（推荐，免手输）**
   - 点底栏「扫描内网」，程序自动识别网段并扫描（约 10–30 秒）
   - 列出发现的设备：主机名 / IP / MAC / 在线状态
   - 勾选需要的，点「保存选中」；也可点「全选在线」一次选完
   - 已在列表中的设备显示「已添加」，不会重复保存

   **方式 B：手动添加**
   - 点「添加机器」，逐项填写（字段见下）
   - **名称**：自定义，如「书房主机」
   - **MAC**：目标机器的有线网卡 MAC，如 `AA:BB:CC:DD:EE:FF` —— **唯一的必填项**
   - **IP**：**留空即可**，程序会自动发现（见下文）。也可手填以固定地址
   - **广播地址**：留空则自动推算
   - **端口**：WOL 端口（UDP），默认 9
   - **探测方式**：自动 / 仅 ping / 仅 TCP，默认自动
   - **探测端口**：TCP 探测端口，默认 445
4. 勾选离线机器 → 点「唤醒选中」

机器数据保存在 exe 同目录的 `machines.json`，本机偏好存 `settings.json`。

### 扫描内网怎么用

点底栏「扫描内网」或在「⋯」菜单里选，会打开扫描窗口：

- **窗口立即出现**，扫描在后台进行，不会卡着等
- **结果实时逐条显示**：找到一台就出现一台（约 0.1 秒起就有结果），不必等扫完
- **网段**默认填好（优先有默认网关的网卡，其次 `192.168.x`），也可手动改
- 完整扫描约 **10–30 秒**，取决于网内设备数量
- 主机名稍后回填（DNS 反查比 IP 探测慢），先显示「未知设备」
- 点「全选在线」一次选中所有在线且未添加过的设备，或逐个勾选
- 已在列表里的设备标注「已添加」，不会被重复保存

**能扫到什么**：所有开机并响应 ARP 的设备——电脑、NAS、路由器、手机、智能家居（米家设备常见）。不开机的设备扫不到，需要手动添加 MAC（或等它开机后再扫）。

**扫描原理**：向网段内 254 个地址发探测包逼出 ARP 缓存，再读系统 ARP 表拿到 IP↔MAC 映射，尔后并发验证存活并反查主机名。只会扫你的真实局域网——会自动排除 Clash/Meta TUN、Tailscale、WSL 这类虚拟网卡网段。

### 两个「端口」的区别

容易混淆，这里说清楚：

| | 用途 | 协议 | 默认 |
|---|---|---|---|
| **端口** | 发魔术包叫醒机器 | UDP | 9 |
| **探测端口** | 判断机器是否开着 | **TCP** | 445 |

一个管「叫醒」，一个管「看醒没醒」，互相独立。默认 445（SMB）是因为 Windows 机器几乎必然监听它。

### 什么时候需要改探测方式

默认的「自动」已经覆盖绝大多数情况：先 ping，ping 不通再试 TCP。

如果某台机器**开了防火墙禁 ping**，自动模式依然能通过 TCP 判定它在线。若你的机器既不响应 ping、又没开 445，把探测端口改成它实际监听的端口（比如远程桌面 3389、SSH 22、Web 80）。

改成「仅 ping」就退回最原始的行为，完全不用 TCP。

### 为什么 IP 不用填

**唤醒只需要 MAC。** WOL 魔术包是一个二层广播帧，内容就是「6 个 0xFF + MAC 重复 16 次」，与 IP 毫无关系。这个工具里 IP 唯一起作用的地方是 **ping 探测在线状态**。

而 DHCP 分配的 IP 会变，所以：

- **留空 IP** → 程序通过 ARP 表反查 MAC 当前对应的 IP，自动填充。ARP 是二层协议，目标机只要开机就会应答（**即使它防火墙禁 ping 也一样能发现**）。IP 变更后会自动跟随更新。
- 发现到的 IP 会存进 `machines.json`，作为「上次已知地址」。机器关机后 ARP 表项消失，但靠这个记录仍能正确显示为「离线」而不是「未知」。
- **手填 IP** → 固定使用该地址，不被自动发现覆盖，适合静态 IP / 需要跨网段探测的情况。

也就是说：填了 IP 就用你填的，不填就自动找。**只填 MAC 完全够用。**

发现的 IP 在列表里正常显示；若某台机器始终找不到（关机中 / 不在同一网段），IP 列显示「自动发现」，状态显示「未知」——此时它仍然**可以正常唤醒**，只是无法判断在线状态。

## 目标机器需要的前置条件

WOL 要生效，被唤醒的机器必须满足以下条件（缺一不可）：

1. **BIOS / UEFI 开启 Wake-on-LAN**
   - 通常在 `Power Management` / `Advanced` 里，名称可能是 `Wake on LAN`、`Power On By PCI-E`、`ErP` 相关选项
   - 部分主板需要关闭 `ErP Ready`（深度节能会切断网卡供电）
2. **网卡驱动设置**（设备管理器 → 网络适配器 → 属性）
   - 「电源管理」标签：勾选 **允许此设备唤醒计算机** + **只允许幻数据包唤醒计算机**
   - 「高级」标签：启用 **Wake on Magic Packet**（魔术包唤醒）
3. **关闭 Windows 快速启动**
   - 控制面板 → 电源选项 → 选择电源按钮的功能 → 更改当前不可用的设置 → 取消「启用快速启动」
   - 快速启动的关机是休眠，网卡可能收不到魔术包
4. **使用有线网卡**
   - 无线网卡的 WOL（WoWLAN）支持极少，基本不可用
5. **唤醒端与被唤醒端在同一广播域**
   - 跨网段需要路由器支持定向广播或 WOL 中继

## 快捷键

| 按键 | 功能 |
|---|---|
| `Ctrl+A` | 全选 / 全不选 |
| `F2` | 编辑选中机器 |
| `Delete` | 删除选中机器 |
| `F5` | 立即重新扫描 |
| `Enter`（对话框内） | 保存 |

行上双击 = 编辑，右键 = 唤醒 / 编辑 / 删除。

## 配色方案

主窗口「⋯」菜单 → **配色方案**，三选一：

| 选项 | 行为 |
|---|---|
| 跟随系统（默认） | 随 Windows 的浅色/深色设置自动切换 |
| 浅色 | 固定白色底 |
| 深色 | 固定深灰底 |

切换立即生效，并写入 `settings.json` 的 `theme` 字段，下次启动沿用。

## 调整窗口大小

窗口无系统边框，拉伸由程序自己实现：

- 鼠标移到**任意边缘或四角**，光标会变成拉伸箭头
- 拖拽即可改变高度（也可改宽度），最小 480×320
- 列表区随高度自适应，底栏始终贴底

## 托盘与关闭行为

点主窗口的 **×** 不会退出程序，而是**隐藏到托盘**，后台继续探测状态。

- **左键单击 / 双击**托盘图标 → 显示主窗口
- **右键**托盘图标 → 菜单（显示窗口、唤醒所有离线、立即刷新、开机自启、退出）

**彻底退出**只有一条路径：托盘右键菜单 →「退出」。

首次最小化会弹一次气泡提示，之后不再打扰。若系统托盘不可用，× 会退回「直接退出」。

## 开机自启

托盘菜单或主窗口「⋯」菜单里都能开关。实现方式是写 `HKEY_CURRENT_USER\...\Run`：

- **不需要管理员权限**（HKCU 而非 HKLM）
- 启动参数带 `--minimized`，开机时静默驻留托盘，不弹窗
- 程序每次启动都会**回读注册表并比对当前路径**。如果在任务管理器里禁用了自启、或把 exe 挪了位置，界面会如实显示为「未启用」，不会出现「显示已开启但开机没反应」

## 导入导出

主窗口标题栏 **「⋯」→ 导入 / 导出机器列表**。

- **导出**：JSON，含版本头；只存配置，不含在线状态
- **导入**：兼容带版本头的导出文件和裸的 `machines.json`
- 导入时**必须先选策略**：
  - **合并**（默认）：按 MAC 去重，已存在的跳过，新的追加
  - **替换**：清空现有列表，完全用文件内容

单条数据非法（缺名称、MAC 格式错）只会被跳过并汇总提示，不会导致整个导入失败。

## 开发

```bash
# 环境
python -m venv .venv
.venv\Scripts\pip install PySide6 pyinstaller

# 运行
.venv\Scripts\python main.py

# 自测（无界面，55 项断言）
.venv\Scripts\python tools\selftest.py

# 渲染各状态截图到 shots/
.venv\Scripts\python tools\shot.py

# 打包
.venv\Scripts\python tools\make_icon.py   # 生成图标
.venv\Scripts\python build.py             # 产出 dist/WakeNow.exe
```
